Research OS — исправление входа и удаление аккаунта
Дата: 2026-08-02

GitHub автоматически не изменялся.

1. В Supabase откройте SQL Editor.
2. Выполните целиком файл:
   supabase/account_closure_v1.sql
   При успехе Supabase покажет: Success. No rows returned.
3. Загрузите в репозиторий файлы из архива с сохранением их путей:
   auth.js
   api/index.js
   login.html
   cabinet.html
   settings.html
   supabase/account_closure_v1.sql
   tests/consent-flow.test.mjs
4. Не удаляйте и не заменяйте остальные файлы проекта.

Что изменено:
- сервер ожидает операции входа и проверки сессии достаточно долго для bcrypt/Supabase;
- браузер больше не остаётся на бесконечной загрузке при сбое проверки;
- повторная авторизация использует постоянный аккаунт из базы — новая регистрация не нужна;
- респондент и исследователь могут удалить свой аккаунт с подтверждением текущим паролем;
- удаление отзывает все сессии и обезличивает логин/идентификатор;
- ответы, consent, временные точки и остальные исторические научные записи физически не удаляются;
- исследователь с активным исследованием не может удалить аккаунт до закрытия/передачи исследования.
